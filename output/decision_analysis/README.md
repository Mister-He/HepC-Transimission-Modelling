# 多准则策略选择（2026-11-12）

`scripts/decision_analysis.R` 的生成结果，方法与论文第一章（肺癌微观模拟）相同：Pareto 有效集 + TOPSIS。输入是 `output/scenarios_2026/` 和 `output/scenarios_2026_jcov/{j000,j050,j090}/` 的逐抽样累计结局（`scenario_cumulative_draws.csv`，2,000 个后验抽样）。命令：`Rscript scripts/decision_analysis.R --root .`（约 20 秒）。

## 方法

- **策略集**：`s17` = 主分析 17 个情景；`s68` = 17 个情景 × 4 个 J 治疗覆盖率（0%、50%、90%、99.995%）。
- **时间范围**：2026–2030、2026–2040、2026–2050；**主决策范围为 2026–2050**（用户决定），2030 年仍用于 WHO 达标判断。
- **准则**：效益 = 相对无治疗避免的新感染数、避免的肝病（DC/HCC）死亡数、2030 年同时达到两个 WHO 目标的概率（每个抽样内为 0/1）；成本 = 折现项目预算（检测、会诊、DAA；不含 DC/HCC 照护及节省）、疗程数。避免数不折现。
- **标准化**：在策略集内做 0–1 min-max 标准化，成本反向编码（1 = 最好）。
- **决策规则**：(a) 预算上限内效益最大（上限取预算范围内的整数）；(b) 相对无治疗每避免一例结局成本最低；(c) Pareto 有效策略中的 TOPSIS（主分析等权重）。另给出每种效益的成本效果前沿（强劣势、扩展劣势，Cantor 1994）。
- **不确定性**：主结果用后验中位数；在每个抽样内重复 Pareto、TOPSIS 和预算规则，报告 P(Pareto 有效)、P(TOPSIS 第一)、P(预算规则最佳)。
- **权重敏感性**：等权重；每个准则权重加倍或设为 0；只看效益；只看成本；以及 1,000 组单纯形均匀随机权重（种子 20261112）。

## 文件

- `decision_criteria_summary.csv`：每个策略集 × 时间范围 × 策略的准则中位数及 95% UI、每避免一例成本（相对无治疗）、是否 Pareto 有效、TOPSIS 接近度与排名、两种每例成本排名、P(Pareto)、P(TOPSIS 第一)、随机权重下第一的比例。
- `efficiency_frontier.csv`：成本效果前沿（状态：frontier / dominated / extendedly dominated，及相对前一个前沿策略的增量成本效果比）。
- `budget_rule.csv`：各预算上限下效益最大的策略及其在抽样中为最佳的比例。
- `topsis_weight_sensitivity.csv`：各权重组的第一名。
- `decision_source.txt`：输入目录、抽样数、时间范围、随机权重数。
- `decision_frontier.png/.svg`（论文图 7）、`decision_topsis.png/.svg`（论文图 8），由 `scripts/figures.py` 生成。

## 主要结果（2026–2050，s17）

- Pareto 有效 8 个。等权重 TOPSIS 第一：**8000/年 F75%**（接近度 0.565；99.2% 的抽样中第一），其次 5000/年 F75%（0.559）、无上限筛查（0.551）。2026–2030 范围内第一为无上限筛查（唯一达到两个目标的策略）。
- 肝病死亡前沿（按成本）：1000/年 F75% → 2000/年 F75% → 5000/年 F75% → 8000/年 F75% → 8000/年 F50% → 无上限；J-only 被 1000/年 F75% 强劣势（成本不高于 J-only 且效益更多）；所有 F25% 情景为劣势或扩展劣势。
- 规则 (b)：每避免一例成本最低为 5000/年 F75%（感染与肝病死亡均是）。
- 权重：肝病死亡或 WHO 达标权重加倍 → 无上限筛查第一；预算或疗程权重加倍 → 5000/年 F75%。随机权重下第一的比例：无上限 48%、5000/年 F75% 18%、8000/年 F75% 17%、2000/年 F75% 15%。
- s68：无上限筛查 + J 99.995% 第一（100% 抽样），前四名都是无上限筛查；同一筛查政策下 TOPSIS 接近度随 J 覆盖率上升。TOPSIS 排名依赖所比较的策略集（s17 与 s68 第一名不同）。
- 局限：权重为假设；感染避免数与疗程数相关；效益不折现；项目预算不含后续肝病照护费用，低估了避免肝病死亡的价值；不使用 QALY（设计如此）。
