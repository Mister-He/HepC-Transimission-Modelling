# Active NPE output guide

This folder contains the active corrected-target NPE training data, two-seed
posterior samples, SBC coverage summaries, configuration, and predictive
caches. The `NPE_OK.txt` or `NPE_NOT_OK.txt` marker is the quality gate. The
accepted rerun uses 3,000 simulations and Normal(0.20) log-scale priors.
Files here are generated results and are overwritten by reruns.
