# NPE vs reference MCMC comparison guide

Cross-validation only; nothing here feeds the production path. Generated by
`scripts/compare_npe_mcmc.R` (comparison) and `scripts/sbc_mcmc.R` (`mcmc_sbc/`); reruns overwrite it.
Start with `report.md`.

- `report.md`, `model_audit.md`: written by hand. `model_audit.md` checks that both methods target the
  same posterior.
- `parameter_comparison.csv`, `accuracy_summary.csv`: per-parameter and summary accuracy against the
  reference, with tolerances |SMD| ≤ 0.1, |95% endpoint| ≤ 0.2 SD and width ratio 0.9–1.1.
- `policy_comparison.csv`: seven predeclared policy outcomes, NPE (1,000 states) against the
  production scenario run (`output/scenarios_2026/`, 2,000 reference MCMC states).
- `figures/`: `marginals.png`, `pairs.png`, `accuracy.png`.
- `policy/npe_lhs/`: the NPE policy draws (`scenario_2030_draws.csv`), draw validity, input states and
  run log. Delete it to rerun after the NPE or the scenarios change.
- `mcmc_sbc/`: direct MCMC SBC on 8 synthetic datasets (`targets_dsXX.json`, one chain per dataset in
  `dsXX/`, `mcmc_sbc_ranks.csv`, `mcmc_sbc_summary.csv`).
