# NPE vs reference MCMC comparison guide

Generated by `scripts/compare_npe_mcmc.R`; reruns overwrite it. Start with `report.md`.

- `model_audit.md`: written check that both methods target the same posterior. Source text; edit by hand.
- `parameter_comparison.csv`, `accuracy_summary.csv`: per-parameter and summary accuracy against the
  reference, with tolerances |SMD| ≤ 0.1, |95% endpoint| ≤ 0.2 SD and width ratio 0.9–1.1.
- `policy_comparison.csv`: seven predeclared policy outcomes (1,000 states each) against the reference.
- `figures/`: `marginals.png`, `pairs.png`, `accuracy.png`.
- `policy/reference/`, `policy/npe_lhs/`: 1,000-state scenario runs (`scenario_2030_draws.csv`, summaries and
  input states).
- `previous_random_npe/rep1..3/`: earlier single-round NPE runs trained on 26,000 random prior simulations, kept
  for context. Each holds posterior draws, the network config, simulation timing and its policy run. Their
  training data were deleted.
