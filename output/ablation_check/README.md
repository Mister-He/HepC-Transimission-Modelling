# Ablation check guide

Reference-MCMC ablation runs for `docs/ablation_check.md`, generated by `scripts/ablation_check.R`. Each
`<run-id>/` folder is one run; reruns with the same ID skip arms that are already complete.

`ab_20261012/` (start with `ablation_report.md`):
- **Run records:**
  - `ablation_config.json`: thresholds and arm definitions, fixed before the run.
  - `run_manifest.json`: commands, seeds, file hashes and per-chain budgets.
  - `driver.log`: the driver's log.
- **Inputs** (`inputs/`): NPE, Hessian and pilot covariances, start files and `hessian_info.json`.
- **Arm folders:**
  - `A_mean/`, `A_disp/`, `A_tail/`, `B_pilot/`, `C_map/`, `D_prior/`: one folder per arm, written by
    `scripts/run_mcmc_reference.R`.
  - `B_pilot_stage1/`: the pilot chains.
  - `dt_daily/`, `dt_monthly/`: the step-size check.
- **Summaries across arms:** `arm_summary.csv`, `diagnostics.csv`, `covariance_eigen.csv`,
  `covariance_drift.csv`, `start_sensitivity.csv`, `npe_vs_mcmc_scale.csv`,
  `dt_chain_comparison.csv`, `dt_deterministic_comparison.csv`, `thinning_evidence.csv`.

Inside each arm folder:
- `mcmc_draws.csv`: draws stored every 10th iteration.
- `mcmc_warmup.csv`: warmup states.
- `mcmc_diagnostics.csv`: R-hat, bulk/tail ESS, MCSE and autocorrelation time.
- `mcmc_per_chain.csv`: per-chain summaries.
- `mcmc_chain_summary.csv`: acceptance, budgets and CPU time.
- `covariance_drift.csv`, `covariance_eigen.csv`, `retained_block_covariance_drift.csv`: adaptation and
  proposal geometry.
- `mcmc_jumps.csv`: proposal jump sizes during warmup.
- `mcmc_traceplots.png`: trace plots.
- `mcmc_run_config.json`, `command.txt`, `run.log`: how the arm was run.

These are generated results. They do not replace the production posterior in
`output/calibration/mcmc_reference/`.
