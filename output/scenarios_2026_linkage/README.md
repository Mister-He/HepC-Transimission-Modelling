# 敏感性分析：社区筛查后的治疗联接率（2026-11-12）

`scripts/scenarios_2026.R --linkage` 的生成结果。与 `output/scenarios_2026/`（主分析，联接率 100%）使用同一后验、同一 2,000 个抽样（`--sample-seed 20261005`），J 治疗覆盖率 99.995%，运行到 2050 年（配置 `end_year`）。唯一改动：F/X 每年的治疗配额 = 筛查发现的慢性感染数 × 联接率 ℓ；未联接者留在状态 c，以后年份可再次被筛查发现。治疗完成率不单独变化（仍假设开始治疗者全部完成）。

| 子目录 | 联接率 ℓ | 命令参数 |
| --- | --- | --- |
| `l080/` | 80% | `--linkage 0.8 --out-dir output/scenarios_2026_linkage/l080` |
| `l060/` | 60% | `--linkage 0.6 --out-dir output/scenarios_2026_linkage/l060` |

每个子目录的文件与 `output/scenarios_2026/` 相同（不含图）。J-only 与主分析相同（J 不受联接率影响）。

- 联接率越低，每个有限情景的效果越小。发病目标达标的有限情景：80% 时 5 个，60% 时 3 个（主分析 5 个）。任何联接率下都没有有限情景达到死亡目标。
- 8000/年 F25%：2030 年肝病死亡降幅 40.5%（80%）、36.6%（60%），主分析 44.0%；2026–2050 相对 J-only 多避免肝病死亡 850、723（主分析 947）。
- 无上限筛查在 80% 和 60% 时仍达到两个目标（肝病死亡降幅 71.0%、68.9%），因为当年未联接者次年会再次被筛查。
- 区间只反映后验参数不确定性。论文：S1 Text 第 17 节，表 U。
