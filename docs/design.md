# 设计理念（Design Philosophy）

本文阐述本仓库迁移与推断流程的核心设计决策与理由。

## 1. 为什么迁移到 NumPyro / JAX

legacy 实现（R + Rcpp/C++）完成了确定性标定（Nelder-Mead）、Laplace 近似与
自适应 Metropolis 推断。迁移到 NumPyro 的核心动机：

- **统一的概率编程 + 自动微分**：NumPyro 提供 NUTS（无 U-turn 采样器），
  相比手写自适应 Metropolis，能利用梯度信息高效探索后验；
- **JAX 生态**：`jit` / `grad` / `vmap` 让模拟器既可用于推断，也可用于
  批量后验预测与敏感性分析；
- **可复现与可维护**：Python + 显式配置，比 R 全局变量 + C++ 更易维护。

## 2. 忠实移植优先（数值等价性）

迁移的第一原则是**不改变模型语义**。JAX 移植严格复刻了 sim.cpp 的：

- 平铺索引与 384 隔室布局；
- RK4 固定步长、每步负值截断与 10 岁年龄带推进（算子分裂的顺序与公式）；
- 频率依赖感染压、层间逮捕/释放流、治疗与死亡流；
- 甚至复刻了 legacy `setup.R` 中 `y0` 的**实际布局偏移**（初始值相对名义
  隔室后移一格）——因为 legacy 的所有结果都是在该布局下产生的。

验证方式：用 R/C++ 在 NM 点估计处生成参考输出（`tests/data/`），JAX 实现
与之逐隔室对照，偏差 ~1e-12（浮点末位）。**移植的正确性因此有硬证据。**

## 3. NUTS 的数值挑战与对策

直接在 12 维 theta 空间跑 NUTS 时，参数后验尺度差异大（sd 0.05–0.5），
启发式步长相当于几十个后验标准差，导致 warmup 步长塌缩、单次迭代
100+ leapfrog 步。三个对策：

1. **白化再参数化**：用 legacy 后验的均值与协方差 Cholesky 做仿射变换，
   在 `u ~ N(0,I)` 空间采样，再变换回 theta 空间。单位尺度下 NUTS 步长
   0.3–0.6、每迭代 7–15 leapfrog，接受率 0.88–0.95，效率提升 1–2 个数量级。
   白化变换是确定性双射（Jacobian 为常数），后验不变。
2. **平衡态惩罚的取舍**：legacy 的 1e6 硬惩罚会在可行域边界形成极陡悬崖，
   破坏 NUTS 几何。我们验证了 **legacy 后验样本 100% 通过平衡态门**，即该
   惩罚在后验质量区域几乎从不激活。因此推断默认不惩罚，在后处理阶段按
   平衡态门过滤 PPC 样本；同时保留 `legacy`（原样 1e6）与 `smooth`
   （平滑二次）两种模式供对照。
3. **计算预算**：完整 150 年 × 日步长的梯度评估约 2 秒，NUTS 全量运行不现实。
   主推断采用 7 天步长（NM 摘要偏差 ≤ 0.27% 人口、0.0003 患病率，远小于
   后验不确定度），并保留 1 天步长的精确模型用于验证与对照。这是明确的
   工程权衡，已在文档中量化。

## 4. 初值与先验：与 legacy 的可比性

用户要求"引入 legacy 的 prior distribution 以及 point estimate 作为 initial
value"。本设计：

- 先验与 legacy `make_priors()` 完全一致（contact log 缩放 Normal、beta log
  缩放 Student-t，锚点取自文献/官方数据）；
- 所有链从 NM 点估计（`legacy/nelder_mead_point_estimate.json`）出发，
  warmup 后自然散开；
- 后验比较在**同一 theta 空间**进行：中位数、95% 区间、区间重叠、
  2 样本 KS 检验，并报告收敛诊断（R-hat/ESS）与 legacy 同标准。

## 5. 配置驱动

所有固定参数（自然史、治疗、接触矩阵、死亡、模拟设置、目标、先验）写入
`config/*.json`。代码只读配置，不改硬编码；修改参数只需编辑 JSON。JSON 中
以下划线开头的字段为说明性注释，加载时自动剔除。

## 6. 严格收敛性与后验预测

- 收敛：R-hat ∈ [0.995, 1.005]（与 legacy 相同标准）、pooled ESS > 1000、
  记录发散数与接受率；
- PPC：目标级（p_hat、N_hat）与数据级（二项计数、人口）双层面，观测落入
  95% CrI 的覆盖率与 Bayesian p 值；
- 比较：新后验 vs legacy 后验的逐参数差异，避免只报"看起来差不多"。

## 7. 工程纪律

- 单元测试锚定 R 参考输出，防止移植回归；
- 集成测试在短时域上跑通端到端推断，保证 CI 可行；
- 结果、诊断与图全部落盘（`results/numpyro_nuts/`），`memo.md` 记录全过程，
  后续 agent 可据此续作。
